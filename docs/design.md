# OurProps — Homepage UI Design Specification

## 1. Purpose

Design a simple, modern homepage for OurProps.

The immediate goal of the homepage is to:

1. Clearly explain what OurProps does.
2. Build trust with visitors.
3. Encourage visitors to join the waitlist.
4. Establish a visual design system that can be reused as the product grows.

The homepage should feel like the beginning of a serious property technology product, not a generic real-estate website.

Do not introduce product terminology or functionality that has not been established.

---

# 2. Product Positioning

OurProps is a platform for organizing and managing property information.

The homepage should communicate that property information can be easier to organize, understand, and access.

Do not make claims about:

- Guaranteed ownership
- Legal title
- Government registration
- Guaranteed verification
- Replacing official land processes

Keep claims factual and simple.

---

# 3. Design Direction

## Overall aesthetic

Modern, clean, trustworthy, and minimal.

The visual language should feel:

- Professional
- Reliable
- Calm
- Modern
- Property-focused
- Technology-driven

Avoid making the product look like:

- A traditional real-estate agency
- A luxury property marketplace
- A government website
- A crypto/blockchain product
- An AI startup landing page

The product should feel like modern infrastructure for property information.

---

# 4. Brand Colors

The OurProps logo defines the primary brand palette.

Do not introduce a separate green brand color.

## Primary Brand — Deep Blue

`#003366`

Use for:

- Navigation
- Headings where appropriate
- Brand elements
- Dark sections
- Footer
- Important product surfaces
- Primary visual structure

Deep blue is the dominant brand color.

## Accent — Orange

`#FF6B35`

Use strategically for:

- Primary CTA buttons
- Important interactive elements
- Highlights
- Active states
- Small visual accents

Orange should communicate action and emphasis.

Do not use orange excessively.

## White

`#FFFFFF`

Use for:

- Cards
- Navigation surfaces
- Product UI
- Text on dark backgrounds
- Clean visual space

## Page Background

Use a very light neutral:

`#F7F9FB`

Use for:

- Main page background
- Large sections
- Application surfaces

## Text

Primary:

`#102A43`

Secondary:

`#52606D`

Muted:

`#7B8794`

## Borders

`#D9E2EC`

## Semantic Colors

Success:

`#2E7D5B`

Warning:

`#B7791F`

Error:

`#C0392B`

Semantic colors should only be used for their respective states and should not compete with the primary OurProps colors.

---

# 5. Typography

Use a modern sans-serif.

Preferred:

**Inter**

Alternative:

**Geist**

Typography should be highly readable with a strong hierarchy.

## Suggested scale

Hero heading:

- Desktop: 56–64px
- Mobile: 40–44px
- Weight: 600–700
- Tight line height

Section headings:

- 36–48px

Card headings:

- 18–24px

Body:

- 16–18px
- Line height: 1.5–1.7

Small UI text:

- 13–14px

---

# 6. Layout

Use a centered content container.

Maximum width:

`1200–1280px`

Desktop horizontal padding:

`24–32px`

Mobile horizontal padding:

`20px`

Use generous whitespace.

The design should feel spacious rather than dense.

---

`PROPERTY INFORMATION, SIMPLIFIED`

**A simpler way to manage property information.**

**Join the waitlist**

`Launching in Ghana`

`Residential`

`1,240 m²`

# 16. Reusable Components

The homepage should establish reusable UI patterns for future development.

Create consistent styles for:

## Buttons

### Primary

- Orange background
- White text
- 8–10px radius
- Medium height
- Clear hover state

### Secondary

- White or transparent background
- Deep blue text
- Subtle border

### Dark-background secondary

- Transparent/outlined
- White text
- White or subtle border

---

## Cards

- White background
- Thin border
- 12–16px radius
- Very subtle shadow
- Generous internal spacing

---

## Status Indicators

Examples:

`Complete`

`Pending`

`In review`

`Action required`

Use both color and text/icon so status does not rely on color alone.

---

## Property Information Rows

Example:

`Property type`

`Residential`

Use a consistent label/value hierarchy.

---

## Document Cards

Show:

- Document name
- Document type
- Date/status

Keep the component compact.

---

## Map Component

Create a reusable map container that can later be used in:

- Property creation
- Property details
- Admin review
- Property viewing

---

# 17. Map Visual Style

Maps should be visually quiet.

Use:

- Light map background
- Simple roads
- Subtle labels
- Clear property boundary
- Minimal controls

The property boundary can use the OurProps orange as an accent.

The map should communicate location and boundaries without becoming the primary visual focus.

---

# 18. Imagery

If imagery is used, use authentic Ghanaian property context.

Prefer:

- Ghanaian residential properties
- Accra neighborhoods
- Land/property environments
- Modern Ghanaian architecture

Avoid generic stock imagery that makes the product feel disconnected from Ghana.

Photography should be secondary to the product UI.

The homepage should still work without photography.

---

# 19. Responsive Design

## Desktop

- Two-column hero
- Horizontal navigation
- Three-column feature cards
- Three-step process
- Large product preview

## Tablet

- Reduce spacing
- Maintain strong hierarchy
- Collapse sections where necessary

## Mobile

- Single-column layout
- Product preview below hero copy
- Full-width CTA
- Stacked feature cards
- Vertical process steps
- Simplified navigation
- Full-width waitlist form

Mobile should feel intentionally designed, not like a compressed desktop page.

---

# 20. Motion

Keep animations subtle.

Use:

- Button hover states
- Small card transitions
- Fade/slide entrance
- Smooth scrolling

Avoid:

- Excessive animations
- Parallax
- Floating blobs
- Constant movement
- Large animated backgrounds

The product should feel calm and trustworthy.

---

# 21. Accessibility

Follow accessible design principles.

- Good color contrast
- Visible keyboard focus
- Semantic HTML
- Clearly labelled form fields
- Accessible buttons
- Minimum approximately 44px touch targets
- Do not communicate status through color alone

---

# 22. Future Design Consistency

The homepage is the foundation for the future OurProps application.

Future screens should reuse:

- Same colors
- Same typography
- Same spacing system
- Same buttons
- Same cards
- Same form controls
- Same status indicators
- Same property information patterns
- Same document components
- Same map components

The marketing website and application should clearly feel like the same product.

---

# 23. Design Principles

1. **Keep it simple**
2. **Clarity over decoration**
3. **Trust over hype**
4. **Product UI over marketing graphics**
5. **Use real interface patterns**
6. **Progressive disclosure**
7. **Consistent components**
8. **Mobile-first usability**
9. **Avoid unsupported product claims**
10. **Design for future reuse**

---

# 24. Avoid

Do not use:

- "Property Passport"
- Blockchain terminology
- Crypto-style visuals
- Generic AI imagery
- Excessive gradients
- Neon colors
- Excessive glassmorphism
- Fake testimonials
- Fake statistics
- Fake customer logos
- Claims of guaranteed ownership
- Claims that OurProps replaces official registration
- Overly complicated navigation
- Excessively dense dashboards
- Unnecessary product features

Do not invent terminology or functionality that has not been provided.

Generate a polished responsive homepage using this specification.

Use the provided OurProps logo as the brand reference.

Prioritize:

- Strong typography
- Excellent spacing
- Clear visual hierarchy
- Deep blue as the dominant brand color
- Orange as the primary action/accent color
- White and light neutral surfaces
- Realistic property-management UI
- Realistic map/property visual
